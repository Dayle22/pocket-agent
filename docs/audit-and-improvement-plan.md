# Pocket Agent audit and improvement plan

24 November 2026 · v0.4.0 · reviewed commit `bbd572b` on Windows

**Recommendation.** Make the next release a reliability update. The companion, drawer and streaming voice already work together. The highest-value changes are protecting a user's draft when an agent disconnects, making Stop and project switching predictable, and ensuring a failed update leaves a usable installation.

## Findings

| Priority | What happens | Evidence |
| --- | --- | --- |
| High | **A disconnected drawer can consume a draft.** The status check finds “connected” inside “disconnected”. Reselecting the current agent then fails to reconnect. Sending clears the editor and adds the prompt to the transcript before the bridge can reject it. The separate Reconnect button is still available. | Reproduced with the real drawer. Reselect emitted zero reconnects, Send emitted one prompt, and the editor was empty. [Connection status](../pocket_agent/ui/drawer.py#L940) · [Submit](../pocket_agent/ui/drawer.py#L1534) |
| High | **Switching during a slow agent handshake leaves the old connection attempt pending.** Cancelling the session runner does not settle the future awaited by the caller. Repeated switches can accumulate unfinished tasks. | Reproduced with two offline subprocesses. The replacement session connected while the original connection task was still waiting. [Connection attempt](../pocket_agent/acp_bridge.py#L634) · [Cancellation branch](../pocket_agent/acp_bridge.py#L735) |
| High | **An interrupted Windows update can leave a mixture of old and new files.** The helper retries a recursive copy over the running installation after a bounded wait. A partial copy has no rollback, and a failed relaunch has no recovery path. | Source finding. The existing test verifies the generated script text and mocks process launch. The download stage already checks the archive checksum and its extraction paths. [Apply helper](../pocket_agent/updater.py#L387) · [Existing test](../tests/test_updater.py#L243) |
| High | **The client's file callbacks do not enforce the selected project.** The handshake leaves ACP file capabilities disabled, but Pocket Agent implements read and write handlers that accept the supplied path and ignore the session ID. “No Project” sets a working directory. It offers no process-level isolation from a local CLI. | Source and installed SDK inspection. A conforming agent should respect the advertised capabilities. The risk concerns requests that nevertheless reach these handlers. [Callbacks](../pocket_agent/acp_bridge.py#L298) · [Handshake](../pocket_agent/acp_bridge.py#L669) · [ACP filesystem contract](https://agentclientprotocol.com/protocol/v1/file-system) |
| Medium | **Stop reports success.** The bridge emits a cancelled outcome, then the app takes the normal completion path, including a speech flush, a celebration and “Done!” when the drawer is hidden. | Reproduced at the app handler with a cancelled outcome. [Bridge](../pocket_agent/acp_bridge.py#L773) · [Completion handler](../pocket_agent/app.py#L653) |
| Medium | **Remote speech starts enabled.** On a fresh profile, speakable assistant replies go to Microsoft's online Edge TTS service. Settings names Edge TTS, but does not explain where the text goes. A reply can quote private project material. | Traced the default, streamed reply handling and synthesis call. [Default](../pocket_agent/config.py#L132) · [Synthesis](../pocket_agent/voice.py#L524) · [Settings](../pocket_agent/ui/settings_page.py#L123) |
| Medium | **A settings file can prevent launch.** The loader recovers from invalid JSON syntax, then assumes every successfully parsed value is an object. A JSON array raises an exception before the window opens. | Reproduced `AttributeError` with a temporary settings file containing `[]`. [Settings loader](../pocket_agent/config.py#L138) |

## Implementation order

Each row is a separately reviewable change. The first three belong in the next Windows release.

| Order | Change | Acceptance check |
| --- | --- | --- |
| 1. Make chat state explicit | Track connection state separately from turn state and display text. Gate Enter and Send on a ready session, preserve the draft until submission is accepted, and show a distinct stopped outcome. Give each connection attempt an owner and settle it on every exit. Clear stale permission cards on disconnect. | A local test agent connects, streams and exits. Its loss preserves the next draft and reselecting it reconnects. Stop during streaming or permission review shows “Stopped”. Switching during startup leaves exactly one active session and no pending old attempt. |
| 2. Match file access to the advertised capabilities | Keep client-side filesystem operations disabled and return the protocol's unsupported-method response until a feature needs them. If enabled later, tie every operation to the active session and an explicitly approved root. Explain in the project picker what the selected folder controls. | Disabled operations create or change no files. Switching away invalidates the old session. The existing agent chat and tool-diff flow still works. |
| 3. Make updates recoverable | Validate the release tag and resolved staging path before cleanup. Install into an app-owned location with a recoverable previous version. Confirm process exit and write access before replacing files, verify the new app starts, then retire the backup. Preserve unrelated files in portable installations. | In disposable Windows installs, exercise a clean upgrade, a locked file, an unwritable destination and a failed relaunch. In every case a working version remains launchable and the outcome is visible. |
| 4. Repair first-run and recovery paths | Explain online voice where it is enabled and offer opt-in for new profiles. Preserve explicit voice preferences on upgrade. Validate settings fields and recover the usable ones. Refresh setup instructions for Codex and Claude. | A fresh install sends no speech text before opt-in. An invalid settings file opens a recoverable app. A Windows user following each revised setup instruction can reach a first reply. |
| 5. Make release checks reflect what users run | Review the existing untracked `uv.lock`, commit an agreed dependency set and use it in CI and releases. Test the oldest supported Python plus the release interpreter. Exercise the packaged EXE against the offline agent and keep the existing GPU and voice tests. | A clean checkout builds the same dependency set. Release CI observes a successful agent handshake and turn from the packaged application. A process merely staying alive for four seconds currently passes the smoke check. [CI](../.github/workflows/ci.yml#L20) · [Release smoke check](../.github/workflows/release.yml#L62) |

## Noticed along the way

- **Two setup commands have drifted.** The README names `@openai/codex-acp` and a Zed-scoped Claude adapter. The maintainers now publish under `@agentclientprotocol`. Use the maintained installation instructions in both the README and the setup guide. [Current README](../README.md#L56) · [Codex adapter](https://github.com/agentclientprotocol/codex-acp#installation) · [Claude adapter](https://github.com/agentclientprotocol/claude-agent-acp)
- **Review the Windows bundle's licensing before the next public release.** The project declares MIT and packages PyQt6. Riverbank offers PyQt under GPLv3 or a commercial licence. Establish which terms cover the distributed build and check its notices and source availability. The repository does not establish whether the publisher holds a separate commercial licence. [Project metadata](../pyproject.toml#L10) · [Riverbank licensing](https://www.riverbankcomputing.com/software/pyqt/intro)
- **A failed background update check can display “Up to date”.** The checker suppresses the error and returns no latest version. The UI treats that result as a successful comparison. Keep the previous status or show “Last check unavailable”. [Silent failure](../pocket_agent/updater.py#L264) · [Status handling](../pocket_agent/app.py#L469)
- **The release workflow inserts tag values directly into PowerShell source.** Tag pushes and manual dispatch are privileged actions here. Pass the values through environment variables and compare them as data before publication. [Release workflow](../.github/workflows/release.yml#L41)
- **Switching projects clears the visible conversation immediately.** A failed connection to the next project leaves the previous transcript inaccessible in the drawer. As a follow-on usability improvement, keep the previous transcript available to copy after a switch. [Project switching](../pocket_agent/app.py#L353) · [Chat reset](../pocket_agent/app.py#L386)

## Verification and limits

- All **72 existing tests passed** on Windows with the repository's Python 3.13 environment and a temporary user profile.
- A disposable agent communicated over the real ACP subprocess transport, negotiated a session, streamed a reply and finished the turn. Separate offline checks exercised disconnect, cancellation, settings recovery and switching during a delayed handshake.
- A temporary copy of the tracked source built the **0.4.0 source distribution and wheel**. The wheel contained the application modules, icon and built-in sprite sheet.
- Live provider sign-in, a fresh frozen EXE launch and applying an update to a real installation were outside the runtime checks. The updater and file-access findings come from source inspection.
